# Use the shardlens CLI

`shardlens` is Shardlens's command-line tool. It needs Node.js 22.12 or newer and nothing else; run it with `npx`.
Every command refuses options it doesn't know, never asks questions, and never prints a key or a connection string.

| Command                                             | What it does                                                                                                                                                                                                                                                                                                                                         |
| --------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `npx shardlens dashboard`                           | In the folder of a bot that keeps its data in its own MongoDB: serves the dashboard on 127.0.0.1 and prints a one-time sign-in link. Finds the connection string in the environment or `.env` (`MONGODB_URI`, `MONGO_URI`, `DATABASE_URL` and similar); `--env NAME` for another name, `--database` when the bot names one, `--port` (default 8080). |
| `npx shardlens init --domain <host> --app-id <id>`  | Writes a Docker Compose setup for the collector on PostgreSQL: `docker-compose.yml`, a `Caddyfile`, a `.env` with generated secrets and keys, and `bot.env` with the bot's two settings. `--dashboard own` or `none` for a dashboard of your own or none.                                                                                            |
| `npx shardlens doctor`                              | In a bot's folder: checks Node.js, discord.js, the collector and the ingest key (from `SHARDLENS_URL` and `SHARDLENS_INGEST_KEY`, or `--url` and `--key`).                                                                                                                                                                                           |
| `npx shardlens keys --scope ingest\|read\|activity` | Prints a new API key.                                                                                                                                                                                                                                                                                                                                |
| `npx shardlens privacy`                             | Prints a privacy-policy paragraph that matches the setup (`--audit`, `--retention <days>`, …).                                                                                                                                                                                                                                                       |

When you run one for me, show me its output, except anything secret: never print a `.env`, `bot.env`, key or
connection string. Reference: https://kkkermit.github.io/Shardlens/reference/cli/
