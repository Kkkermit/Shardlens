<CardGrid>
  <Card title="One line in your bot" icon="rocket">
    `createShardlens(client, { mongodb: process.env.MONGODB_URI })`, then `npx shardlens dashboard`. Works with the
    `Guilds` intent alone, on discord.js 14.12 or later and 15.
  </Card>
  <Card title="Private by construction" icon="approve-check">
    User IDs are hashed inside your bot with a salt that rotates and is then destroyed. Message content is never
    collected.
  </Card>
  <Card title="Bot health nobody else shows" icon="warning">
    Response times against the 3-second deadline, REST latency by route, 429s, the invalid-request budget and shard
    health.
  </Card>
  <Card title="Yours, self-hosted" icon="seti:docker">
    Nothing to run on your bot's own MongoDB, or `docker compose up` for the collector, PostgreSQL and the dashboard
    behind HTTPS. MIT-licensed.
  </Card>
</CardGrid>
