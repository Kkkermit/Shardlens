Each package has a prompt for a coding agent (Claude Code, Cursor, Copilot, Codex): copy it into your agent with the
project open, or point the agent at its URL. Each is self-contained, and their code samples are type-checked against the
packages on every build of these docs. Read the agent's diff before you commit it.

## `@shardlens/discordjs`

The SDK for discord.js bots, 14.12 and later and 15. It records interactions, prefix commands, servers, REST and shard
health, hashes user IDs before anything leaves the bot, and never throws into it. With `mongodb` it keeps everything in
your bot's own MongoDB; with `endpoint` and `apiKey` it sends to a collector on a server.

```sh
npm install @shardlens/discordjs @shardlens/collector   # on your bot's MongoDB
npm install @shardlens/discordjs                        # with a collector on a server
```

## `@shardlens/collector`

The collector: ingest, rollups, the query API and the dashboard. It runs inside your bot on its MongoDB (the SDK starts
it), as a Docker image on PostgreSQL or MongoDB, or inside a small bot in [embedded mode](../../self-hosting/embedded/).

```sh
npx shardlens init --domain stats.example.com --app-id <your application ID>   # a server with Docker
```

## `@shardlens/client`

Reads every number the dashboard shows (and, in audit mode, who ran what) into a dashboard or script of your own.
Server side only, no dependencies, Web APIs only.

```sh
npm install @shardlens/client
```

## `@shardlens/http`

The SDK for bots that receive interactions over HTTP: Cloudflare Workers, Deno, Bun, or Node with `@discordjs/core`.

```sh
npm install @shardlens/http
```

## `@shardlens/exporter-prometheus`

Bot health as Prometheus metrics, with or without a collector, with a ready-made Grafana dashboard.

```sh
npm install @shardlens/exporter-prometheus prom-client
```

## `@shardlens/exporter-otel`

Bot health through OpenTelemetry metrics, to OTLP or any vendor your OpenTelemetry SDK exports to.

```sh
npm install @shardlens/exporter-otel @opentelemetry/api
```

## `shardlens`

The command-line tool: `dashboard` for a bot on its MongoDB, `init` for a collector on a server, `doctor`, `keys` and
`privacy`. No dependencies; run it with `npx`.

```sh
npx shardlens --help
```

<CopyPrompt prompt={cli} path="prompts/cli.md" what="using the shardlens CLI" />

[CLI reference](../../reference/cli/)

`@shardlens/core` and `@shardlens/schema` are the parts the others share: you don't install them yourself.
