Open your bot's repository in a coding agent (Claude Code, Cursor, GitHub Copilot, Codex, Windsurf or similar), paste
the prompt below and let it work. It works out your setup first: TypeScript or JavaScript, ESM or CommonJS, the
discord.js guide layout, a framework such as Sapphire or discordx or a handler of your own, and single-process bots,
`ShardingManager`, internal sharding or discord-hybrid-sharding. If your bot uses MongoDB, it sets Shardlens up on that
same database, with nothing else to run; otherwise for a collector on a server. Then it creates Shardlens next to your
client, wraps your handlers, records prefix commands if you have them and flushes on shutdown (in the manager too, for
a sharded bot).

## Point your agent at a URL instead

The same prompt is served as plain Markdown, so you can skip the copying:

```text
Add Shardlens to this bot by following https://kkkermit.github.io/Shardlens/install.md
```

The prompt is self-contained: it explains what Shardlens is, how to find your client and handlers, what to do for each
sharding mode and each database, what the agent must not change, and how to check its work. Its TypeScript samples are
type-checked against the real packages on every build of these docs. Two rounds of coding agents installed Shardlens
into four differently built bots from this prompt alone, and their notes made it what it is: see
[testing](../../contributing/testing/#simulated-installs).

<Aside type="caution" title="Review what it did">
  Read the diff before you commit, as with any generated change. The prompt tells the agent not to touch intents, not
  to turn on audit mode, never to write or print a key or a connection string, never to let a Shardlens setting stop
  your bot from starting, and not to add anything you didn't ask for. Check that it listened.
</Aside>

## What the agent leaves to you

- **On MongoDB:** start the bot, run a command, then `npx shardlens dashboard` in the bot's folder and open the link it
  prints.
- **With a collector on a server:** start one ([quick start](../quick-start/#without-mongodb-run-the-collector-on-a-server)),
  set `SHARDLENS_URL` and `SHARDLENS_INGEST_KEY` wherever your bot runs, and run `npx shardlens doctor` from your
  bot's folder to check the connection.

every page.
