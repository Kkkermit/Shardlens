If you already run Prometheus or an OpenTelemetry pipeline, Shardlens can send its bot-health metrics there. You can
use an exporter **instead of** a collector (leave out `endpoint` and `apiKey`) or **as well as** one.

## Privacy and cardinality

- **No user or server labels.** Exporters see events before hashing, with user fields blanked and audit-mode
  identities removed, and no metric is labelled by user or server ID. That keeps your metrics anonymous and their
  cardinality bounded.
- Labels are command names, bucketed REST routes (`/channels/:id/messages`), statuses, shard numbers and the custom
  event names you chose.
- Counts are exact: exporters see every event before any `sampleRate` sampling.

## What you don't get without a collector

Exporters cover bot health. Product analytics (unique users, retention, servers, growth, audience) need the
collector, because they depend on salted user hashes and long-term storage.
