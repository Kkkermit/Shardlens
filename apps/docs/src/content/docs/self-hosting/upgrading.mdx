## Upgrading the collector

<Steps>

1. Back up the database ([Backups](../../operations/backups/)).
2. Read the release notes for anything marked as breaking.
3. Pull the new image and restart:

   ```sh
   docker compose pull && docker compose up -d
   ```

</Steps>

The collector applies database migrations when it starts, under an advisory lock, so several collectors can be
upgraded at once. Migrations only move forward. To roll back, restore the backup you took and run the previous image.

## Upgrading the SDK

Update `@shardlens/discordjs` like any other dependency. You can upgrade the SDK and the collector in either order
within the same major version.

## Version policy

- Packages follow [semantic versioning](https://semver.org). Breaking changes only come in major versions, with a
  migration note.
- The **wire format** has its own major version (`v` in every batch). A collector accepts the current and the previous
  major version, so you never have to upgrade every bot on the same day.
- The collector image is tagged by full version (`1.2.3`), minor (`1.2`) and major (`1`). Pin a major version in
  production.
- Each release lists its changes in the package changelogs, generated by Changesets.
