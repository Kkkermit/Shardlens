Significant decisions are recorded as short architecture decision records (ADRs) in
[`docs/adr`](https://github.com/Kkkermit/Shardlens/tree/main/docs/adr). Each one states the context, the decision and
its consequences. A new decision that changes an old one gets a new record, and the old one is marked as superseded.

| ADR | Decision |
| --- | --- |
| [0001](https://github.com/Kkkermit/Shardlens/blob/main/docs/adr/0001-salted-user-hashing.md) | Pseudonymise user IDs in-process with rotating, destroyed salts |
| [0002](https://github.com/Kkkermit/Shardlens/blob/main/docs/adr/0002-audit-mode.md) | Audit mode is a two-sided, encrypted, time-limited opt-in |
| [0003](https://github.com/Kkkermit/Shardlens/blob/main/docs/adr/0003-storage.md) | PostgreSQL by default, partitioned, no extensions |
| [0004](https://github.com/Kkkermit/Shardlens/blob/main/docs/adr/0004-schema-versioning.md) | Wire-format versioning: additive within a major |
| [0005](https://github.com/Kkkermit/Shardlens/blob/main/docs/adr/0005-typescript-6-pin.md) | Pin TypeScript to 6.0.x |
| [0006](https://github.com/Kkkermit/Shardlens/blob/main/docs/adr/0006-intents-reverification.md) | Gateway intents re-verified against Discord's docs |
| [0007](https://github.com/Kkkermit/Shardlens/blob/main/docs/adr/0007-m0-reference-code-changes.md) | Changes to the spec's reference code during M0 |

To propose a decision, copy
[`0000-template.md`](https://github.com/Kkkermit/Shardlens/blob/main/docs/adr/0000-template.md) to the next number and
open a pull request.
